# GPU要件の見積もり（2026-11-07 時点の机上見積もり）

結論：**BF16対応・VRAM 24GB のGPU 1枚** で主実験まで回せる。80GB級は不要。
計画書の「BF16対応の24GB級をPoC候補」は妥当。

## モデル別

| 対象 | 必要VRAM | 備考 |
|---|---|---|
| EmbeddingGemma 2 凍結＋head | 〜3GB | 740M級の小型モデル。head学習はCPU級 |
| EmbeddingGemma 2 部分更新 | 〜10GB以内 | T4 16GBでも可 |
| SigLIP 2 凍結＋head | 〜6GB以内 | 凍結推論のみ |
| DINOv3 ViT-H+ 凍結検索（再測する場合） | 〜8GB以内 | 文献値はViT-H+/16。小さいViTで測った値を再現値と呼ばない |
| Qwen3-VL 8B 推論 BF16 | 約19.6GB＋活性化分 | 24GBで batch=1・画像サイズ上限つき。16GBでは量子化必須になり公式条件の追試と言いにくい |
| Qwen3-VL 8B 公式方式の追加学習 | 24GB | 原論文が L4 24GB で 20,000ペア・1 epoch と記載。QLoRA 実例も Colab L4 でピーク 23.4GB |
| Qwen3-VL 8B 全層更新 | 約128GB級 | 計画対象外。やるなら複数枚 80GB が必要 |

候補機種：L4 / RTX 4090 / RTX 3090 / A10G（すべて24GB）。速度重視なら 4090。
A100 40GB は「公式学習スクリプトが24GBに収まらなかった時の保険」としてのみ検討。

## GPU時間の概算（実測後に必ず更新すること）

- 凍結特徴の抽出＋head学習（第1〜4週）：10〜20時間
- Qwen 推論：Task 1＋Task 2 で 1評価あたり 1〜3時間
- Qwen 追加学習：1 run あたり 4〜12時間（LoRA系の一般的な実例レンジ）
- 主比較（3 seed）まで含めた総量：**60〜150時間程度**

## その他

- ストレージ：データ約24GB（圧縮時）＋展開＋特徴＋チェックポイントで 150〜200GB を確保。
- ホストRAM：データローディング用に 32GB 推奨（Muse の VM は 7.7GB しかなく、GPU作業は担わない）。
- Colab を使う場合：セッション切断を前提に、再開可能なチェックポイント保存と
  特徴キャッシュの永続化を先に実装する。レンタル（RunPod / Vast 等、24GB級で
  概ね $0.3〜0.8/時）なら総額でも数千円〜1万円台の見込み（概算）。

## GPUコスト調査（2026-11-07、各社公開価格と実測レポートに基づく）

前提：本研究の総量は L4 換算で 60〜150 GPU時間（机上見積もり）。

| 選択肢 | 実効単価 | 備考 |
|---|---|---|
| Colab Pro（$9.99/月、100 CU） | L4 約 $0.17/時（1.71 CU/時の実測ベース、100 CU で L4 約58時間/月） | Google は単価表を公開していない。全て実測ベースの推定。10月末に単価上昇の報告あり（未確認） |
| Colab Pro+（$49.99/月、600 CU） | L4 約 $0.14/時 | バックグラウンド実行可。単価あたりは最安級 |
| RunPod Pod・RTX 4090 Community | $0.34/時 | 秒単位課金。4090 はメモリ帯域 1,008 GB/s で L4（300 GB/s）より大幅に速く、ジョブ時間自体が縮む |
| RunPod Pod・L4 Community / Secure | $0.44 / $0.59/時 | 在庫と安定性は Secure が上 |
| RunPod Pod・RTX 3090 Community | $0.22/時 | 24GB で最安級。BF16 性能は Ampere 世代なり |
| RunPod ストレージ | ネットワークボリューム $0.07/GB/月（公式ドキュメント） | 150GB で約 $10.5/月。Pod を terminate しても残る。転送料無料 |

Colab の制約：GPU の割り当て保証なし、セッション上限（Pro で 24 時間）、
CU は 90 日で失効、データは毎回 Drive 経由か再ダウンロードが必要。
RunPod の強み：SSH で無人実行でき、チェックポイントが永続化され、
この研究の「スクリプトを実行するだけ」の運用と相性が良い。

総額の目安（¥150/$ 換算の概算）：
- Colab Pro を 3 か月使い切る：約 $30（約 ¥4,500）で L4 約 174 時間まで賄える計算。
  ただし月 58 時間のペース配分と割り当て運に依存する。
- RunPod 4090 Community：4090 の速さでジョブ時間が 30〜90 時間に縮むと仮定して
  $10〜31（約 ¥1,500〜4,600）＋ストレージ月 $10 前後。

結論：現金の時間単価だけなら Colab Pro が最安。ただし確実に終わらせるなら
RunPod の 4090 Community が総額でも同等以下になりやすい。
フェーズ分けが現実解：M3（軽い特徴抽出）は Colab、M4（Qwen の長時間学習）は RunPod。
